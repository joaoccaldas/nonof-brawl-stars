## 🔑 Strategic Insights

### João's Leadership Style
- Pushes margin truth over topline comfort
- Insists on explanation quality, not just number finding
- Uses surveys as operational input
- Builds capability + ownership with clear guardrails
- Moving team from manual production to system/data design

### Structural Weaknesses (Recurring Patterns)
1. **Weak interface design** — ownership ambiguity across teams
2. **Broken/misleading reporting logic** — system vs operating truth gaps
3. **Master-data/channel-mapping mismatches** — ongoing data quality issues
4. **Fragmented communication** — late/incorrect info from central to regional
5. **Person-system dependency** — too much tacit knowledge in few people

### Why This Matters for Automation
- High manual retrieval/reconciliation workload → automation opportunity
- Repeated file-level work → templated generation opportunity
- Weak process ownership → needs clear workflow documentation first
- Data scattered across SAP/BW/Excel → unified data layer needed
